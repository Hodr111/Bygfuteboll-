# Pocket Football FC MAX V9

V9 focada em conta online e coleção:

- Google Login real
- recuperação por código de 6 dígitos por e-mail
- ID público PF permanente
- PostgreSQL + RLS
- Gold/Gems/OVR/cartas/estádio/estatísticas persistentes
- packs processados no banco
- ranking global
- catálogo de jogadores reais para protótipo
- avatares controlados pelo jogo, sem upload de imagem
- estádio 3D low-poly
- câmera mobile, controles touch, partida, pênaltis e eventos

A autenticação e o banco dependem da configuração do Supabase/Google descrita em SETUP_V9.md.
