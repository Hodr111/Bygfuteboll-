# Pocket Football FC MAX

Jogo de futebol mobile/web com partidas, cartas, clubes, jogadores, evolução e sistema de conta.

## Recursos

- Partida de futebol 11x11
- Jogadores e clubes
- Cartas com raridade e OVR
- Elenco e coleção
- Gold, Gemas e XP
- Vitórias, gols e estatísticas
- Ranking global
- Temporadas e divisões
- Missões e recompensas
- Packs de cartas
- Estádios
- Uniformes
- ID PFC exclusivo para cada conta
- Login por Google
- Recuperação de conta por e-mail
- Backend Node.js
- Banco de dados próprio
- Sistema preparado para WebSocket
- Painel administrativo
- Sistema de manutenção
- Sistema de banimento
- Sistema de economia
- Loja preparada para futura ativação
- Estrutura preparada para evolução dos gráficos 3D
